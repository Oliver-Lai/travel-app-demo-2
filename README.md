# 旅遊文案生成器 Demo

這是一個手機APP預覽介面，用於演示旅遊文案生成器的功能。使用者可以上傳旅遊照片，按照行程順序排列，然後生成適合社群媒體發佈的文案。

## 功能特色

### 📸 照片上傳
- 支援拖拽上傳或點擊選擇照片
- 支援 JPG、PNG 格式
- 即時照片預覽
- 可移除不需要的照片

### 🔄 照片排序
- 直觀的拖拽排序功能
- 數字標示照片順序
- 流暢的動畫效果

### ✨ 文案生成
- 模擬 AI 文案生成過程
- 生成適合社群媒體的旅遊文案
- 包含 hashtag 標籤
- 載入動畫效果

### 📱 社群分享
- Instagram 分享（模擬）
- Facebook 分享（模擬）
- Twitter 分享（模擬）
- 複製文案功能

## 使用方法

1. **開啟應用程式**
   - 用瀏覽器開啟 `index.html` 文件
   - 建議使用手機或開啟瀏覽器的手機模擬模式

2. **上傳照片**
   - 點擊「選擇照片」按鈕或直接拖拽照片到上傳區域
   - 可以上傳多張照片
   - 不滿意的照片可以點擊右上角的 X 移除

3. **調整順序**
   - 在第二步中，長按並拖拽照片來調整順序
   - 照片會按照您排列的順序來生成文案

4. **生成文案**
   - 點擊「下一步」後會模擬 AI 生成文案的過程
   - 生成完成後可以預覽文案內容

5. **分享文案**
   - 可以模擬分享到各大社群平台
   - 點擊「複製文案」可以複製到剪貼簿

## 自訂設定

您可以根據需要修改以下內容：

### 修改樣式
在 `styles.css` 中調整：
- 顏色主題（目前使用藍紫色漸層）
- 字體大小和間距
- 動畫效果

### 修改文案模板
在 `index.html` 中的 `.generated-content` 區域修改預設文案內容

### 添加功能
在 `script.js` 中可以：
- 添加更多文件格式支援
- 實現真實的 API 整合
- 增加更多互動功能
